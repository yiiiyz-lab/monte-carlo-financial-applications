# Monte Carlo Applications in Finance

A collection of Python-based quantitative research projects exploring financial uncertainty, portfolio risk, and stochastic simulation through Monte Carlo methods.

## Research Projects

### 01 | Portfolio Risk & Loss Probability Simulation

**Status: Completed**

Developed a Python-based Monte Carlo simulation to estimate Value at Risk (VaR), Expected Shortfall (ES), and downside loss probabilities for a $100M multi-asset portfolio.

The study includes:

- **Risk Measurement:** 50,000 Monte Carlo simulation paths to estimate portfolio loss distributions, VaR, ES, and downside probabilities.
- **Model Validation:** Convergence testing and consistency checks to assess simulation reliability.
- **Sensitivity Analysis:** Evaluation of volatility, correlation, drift, and return distribution assumptions.
- **Research Reporting:** Comprehensive methodology, empirical findings, eight visualizations, and model limitations.
